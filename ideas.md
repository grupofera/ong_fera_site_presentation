# 🎨 Brainstorming: Design da Página de Detalhes do Projeto ONG FERA

## Contexto
Criar uma página web que apresente os detalhes técnicos e visuais do projeto do site da ONG FERA de forma atraente, profissional e inspiradora. A página deve comunicar a qualidade do trabalho realizado, documentar as decisões de design e servir como portfólio.

---

## <response>
### Abordagem 1: Minimalismo Corporativo com Foco em Clareza

**Design Movement:** Corporate Minimalism com influências de Design Systems modernos

**Core Principles:**
- Hierarquia extremamente clara através de tipografia e espaçamento
- Fundo branco/cinza neutro com acentos em verde-musgo (da ONG)
- Informações organizadas em blocos bem definidos e separados
- Ênfase em legibilidade e navegação intuitiva

**Color Philosophy:**
- Branco puro (`#FFFFFF`) como fundo principal
- Verde-musgo (`#4a7c59`) como cor primária para destaques e CTAs
- Cinza claro (`#F5F5F5`) para seções alternadas
- Preto/Cinza escuro (`#1a1a1a`) para texto
- Laranja-coral (`#ff6b35`) para elementos secundários de destaque

**Layout Paradigm:**
- Grid de 12 colunas com seções em container centrado
- Alternância entre full-width e container-width
- Cards informativos com bordas sutis
- Sidebar com índice de navegação (desktop)

**Signature Elements:**
- Ícone de pata 🐾 como marca visual recorrente
- Cards com borda esquerda em verde-musgo
- Linhas divisoras horizontais sutis
- Badges com tags de tecnologia

**Interaction Philosophy:**
- Hover effects suaves em cards (elevação sutil)
- Scroll suave para seções
- Transições de 300ms em todas as interações
- Indicador visual de seção ativa na navegação

**Animation:**
- Fade-in ao entrar na viewport
- Slide-up suave para cards
- Pulse sutil em CTAs
- Underline animation em links

**Typography System:**
- **Títulos:** Poppins Bold (700) para H1, Semi-Bold (600) para H2
- **Subtítulos:** Inter Semi-Bold (600) em tamanho menor
- **Corpo:** Inter Regular (400) com line-height 1.6
- **Destaque:** Poppins Medium (500) para labels e badges

**Probability:** 0.08

</response>

## <response>
### Abordagem 2: Design Narrativo com Storytelling Visual

**Design Movement:** Editorial Design + Data Visualization

**Core Principles:**
- Contar a história do projeto através de uma narrativa visual
- Combinar elementos gráficos com dados e estatísticas
- Criar uma jornada emocional enquanto apresenta informações técnicas
- Usar imagens e ilustrações para quebrar monotonia textual

**Color Philosophy:**
- Gradiente suave de verde-musgo para laranja-coral como fundo de seções
- Fundo branco para seções de conteúdo principal
- Cores vibrantes para gráficos e infográficos
- Paleta de 4-5 cores principais com variações

**Layout Paradigm:**
- Seções full-width com imagens de fundo
- Texto sobreposto em imagens com overlay semi-transparente
- Timeline visual para histórico de conversas
- Infográficos customizados para stack técnico

**Signature Elements:**
- Ilustrações customizadas de animais (conexão com ONG)
- Timeline visual com marcos do projeto
- Badges animadas para tecnologias
- Gráficos de impacto (estatísticas da ONG)

**Interaction Philosophy:**
- Hover effects que revelam mais informações
- Animações ao scroll que ativam elementos
- Cliques em timeline para expandir detalhes
- Transições suaves entre seções

**Animation:**
- Parallax suave em imagens de fundo
- Counter animation para números/estatísticas
- Slide-in para elementos ao entrar na viewport
- Bounce suave em botões

**Typography System:**
- **Títulos:** Poppins Bold (700) com tamanho grande e espaçamento generoso
- **Subtítulos:** Poppins Semi-Bold (600) em cor secundária
- **Corpo:** Inter Regular (400) com bom contraste
- **Destaques:** Poppins Medium (500) em cor primária

**Probability:** 0.07

</response>

## <response>
### Abordagem 3: Design Modular com Ênfase em Componentes

**Design Movement:** Component-Driven Design + Glassmorphism

**Core Principles:**
- Construir a página com componentes reutilizáveis e bem definidos
- Usar efeito glassmorphism para profundidade e modernidade
- Criar um sistema visual coeso e escalável
- Enfatizar a qualidade técnica através do design

**Color Philosophy:**
- Fundo gradiente suave (branco a cinza muito claro)
- Componentes com fundo semi-transparente (glassmorphism)
- Verde-musgo e laranja-coral como cores de ação
- Sombras suaves para criar profundidade

**Layout Paradigm:**
- Grid responsivo com cards/componentes como unidades principais
- Componentes podem ser reorganizados em diferentes breakpoints
- Uso de espaçamento consistente baseado em escala 8px
- Componentes com bordas arredondadas e sombras suaves

**Signature Elements:**
- Cards com efeito glassmorphism (backdrop-filter blur)
- Ícones customizados para cada seção
- Badges com gradientes suaves
- Componentes com hover effects que revelam detalhes

**Interaction Philosophy:**
- Interações baseadas em componentes (cada card é interativo)
- Hover effects que elevam e revelam mais informações
- Cliques que expandem componentes para mostrar detalhes
- Transições fluidas entre estados

**Animation:**
- Fade-in ao carregar a página
- Scale-up suave ao hover
- Rotate suave em ícones
- Shimmer effect em componentes ao carregar

**Typography System:**
- **Títulos:** Poppins Bold (700) com tracking aumentado
- **Subtítulos:** Poppins Medium (500) em cor secundária
- **Corpo:** Inter Regular (400) com espaçamento generoso
- **Labels:** Inter Semi-Bold (600) em tamanho pequeno

**Probability:** 0.06

</response>

## Decisão Final

**Abordagem Escolhida: Minimalismo Corporativo com Foco em Clareza**

Esta abordagem foi selecionada porque:

1. **Profissionalismo:** Comunica a qualidade técnica do projeto de forma clara e confiável
2. **Acessibilidade:** Fácil de navegar e entender para qualquer visitante
3. **Escalabilidade:** Estrutura modular que permite adicionar mais conteúdo no futuro
4. **Coerência:** Alinha-se com a identidade visual já estabelecida da ONG FERA
5. **Performance:** Design limpo e simples garante carregamento rápido

### Decisões de Design Específicas

- **Paleta de Cores:** Verde-musgo (`#4a7c59`) + Laranja-coral (`#ff6b35`) + Cinza neutro
- **Tipografia:** Poppins para títulos + Inter para corpo (já utilizado no site original)
- **Layout:** Container centrado com seções alternadas (full-width e container-width)
- **Componentes:** Cards com borda esquerda em verde, badges de tecnologia, timeline visual
- **Animações:** Transições suaves (300ms), fade-in ao scroll, hover effects sutis
- **Navegação:** Índice lateral (desktop) + menu mobile responsivo
